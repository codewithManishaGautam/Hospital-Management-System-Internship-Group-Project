Admin Module Documentation
1. Introduction
The Admin Module is one of the most important modules of the Hospital Management System. It provides complete administrative control over hospital operations such as doctor management, staff management, patient monitoring, and dashboard analytics.
The Admin Panel acts as the central control system where administrators can monitor hospital activities and manage hospital resources efficiently.
2. Objective
The main objectives of the Admin Module are:
• To manage hospital staff and doctors
• To monitor patient records
• To provide hospital statistics and analytics
• To maintain centralized administration control
• To improve hospital workflow management
4. Features
Dashboard Features
• Total Doctors Count
• Total Staff Count
• Total Patients Count
• Admitted Patients Count
• Discharged Patients Count

Staff Management
• View all staff details
• Add new staff
• Edit staff information
• Delete staff records
Doctor Management
• View doctor cards
• Display specialization and experience
• Edit doctor information
• Delete doctor records
Patient Monitoring (Planned)
• View patient details
• Track admission status
• Monitor patient records
Additional Features
• Responsive Design
• Modern UI Cards
