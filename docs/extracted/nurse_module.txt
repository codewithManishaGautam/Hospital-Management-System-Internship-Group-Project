Hospital Management System – Nurse Module

 Introduction
The Nurse Module is an important part of the Hospital Management System (HMS).
It is designed to help nurses manage patient activities digitally in a paperless environment.
This module helps nurses to:
Search patient records
View patient details
Update activity charts
Manage medicines
Add daily reports
Handle shift handover
Generate PDF reports
Send reports to the Pharmacy Module
The system improves hospital workflow, reduces paperwork, and increases communication between nurses and other hospital departments.
 Objectives
Main Objectives of Nurse Module is:
To maintain patient records digitally
To reduce paperwork in hospitals
To improve nurse communication during shift changes
To track patient activities and medicines
To generate reports automatically
To send prescription reports to pharmacy digitally
 Scope of the Project
The Nurse Module is used inside hospitals by authorized nurses only.
The module includes:
Patient Search
Patient Monitoring
Activity Chart Management
Medicine Tracking
Shift Handover
PDF Report Generation
